Code used to implement the ROTATE approach (Ročková and George, 2016) was obtained from [http://veronikarock.com/FACTOR_ANALYSIS.zip](http://veronikarock.com/FACTOR_ANALYSIS.zip). 
The main functions for the ROTATE approach are available in `automatic_RockovaGeorge.R`, while an user-friendly wrapper is available in `AutomaticSparsity.R`.

# REFERENCES

Ročková, V., & George, E. I. (2016). Fast Bayesian factor analysis via automatic rotations to sparsity. Journal of the American Statistical Association, 111(516), 1608-1622.
